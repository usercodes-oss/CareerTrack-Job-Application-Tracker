CareerTrack - Simple version

Files:
- index.html: webpage and forms
- style.css: webpage appearance
- script.js: login, profile, and job application features

How to run:
1. Keep all three files in the same folder.
2. Open index.html in your browser.
3. Create an account, then add profile and job application details.

Features kept:
- Sign up and sign in
- Profile name, email, and skills
- Add/search/filter job applications
- Change status, save/unsave, delete jobs
- Dashboard totals and activity list
- Data saved separately for each account in browser localStorage

Note:
This is a beginner demo, not a secure real-world login. Passwords are stored in browser localStorage for simplicity. For real accounts, use a secure backend and database.
